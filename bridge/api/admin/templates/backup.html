Changer de VPS en 4 étapes

  1. Ici, cliquez Télécharger la sauvegarde.
  2. Sur le nouveau VPS, déployez le dépôt GitHub avec Dokploy (mêmes variables : ADMIN_PASSWORD…).
  3. Faites pointer le domaine dramabiliki.digitlab.dev vers l'IP du nouveau VPS (DNS) et ajoutez-le dans Dokploy → Domains (port 8090).
  4. Ouvrez l'admin du nouveau serveur → Sauvegarde → Importer. L'application mobile continue de fonctionner sans mise à jour, car elle utilise le domaine.
